Installation
============

Requirements
------------

- Python 3.10+
- Railway account and project access

Install from source
-------------------

.. code-block:: bash

   git clone https://github.com/0xdps/railway-deploy.git
   cd railway-deploy
   python -m pip install -U pip
   python -m pip install -e .

You can also install runtime dependencies directly:

.. code-block:: bash

   python -m pip install -r requirements.txt
