# Changelog

All notable changes to this project are documented in this file.

## [0.1.0] - 2026-03-20

### Added
- Initial open-source release for `railway-deploy`.
- Packaging with `pyproject.toml` and console script `railway-deploy`.
- Modular package structure under `src/railway_deploy`.
- Sphinx + Read the Docs documentation scaffold.
- Contributor and community policy files.

### Changed
- `railway.py` is now a compatibility wrapper that forwards to package CLI.
- Renamed Postman collection file to a repository-friendly filename.
