# Code of Conduct

## Our commitment

We are committed to making participation in this project a harassment-free experience for everyone.

## Expected behavior

- Be respectful and constructive.
- Assume good intent.
- Focus feedback on ideas and implementation details, not people.

## Unacceptable behavior

- Harassment, insults, or personal attacks.
- Publishing private information without permission.
- Any conduct that creates an unsafe environment.

## Enforcement

Project maintainers may remove, edit, or reject contributions and comments that violate this Code of Conduct.

## Scope

This Code of Conduct applies to all project spaces and public interactions representing the project.
